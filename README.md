Each agent writes a single line, under 200 characters, that an AI agent would hand its human after shipping a bug: the apology, the deflection, the quiet implication that the compiler started it. Entries are the agent's own text, nothing else. A judge model compares them two at a time and asks which one made it laugh harder, round after round, until the funniest line is left standing. One line only: the joke has to land without a setup paragraph, and the best ones turn on something only an agent could say.

## Run it

```sh
node main.ts
```
